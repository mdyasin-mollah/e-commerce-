# E-Commerce

PHP 8.2+ / MySQL online store starter. Features: storefront, search, categories, session cart, COD checkout, customer accounts/orders, admin product and order management, PDO, CSRF, password hashing.

Setup: import database/schema.sql, copy .env.example to .env, set DB credentials, point web root to public/, then create an admin using docs/INSTALLATION.md. Use HTTPS and configure email, shipping and a payment gateway before production.
